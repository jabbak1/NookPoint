# NookPoint @VERSION@

E-book reader for the **Nook Simple Touch** (Android 2.1, E Ink) and other old Android devices, inspired by the CrossPoint Reader firmware.
Читалка для **Nook Simple Touch** (Android 2.1, E Ink) и других старых Android-устройств, вдохновлена прошивкой CrossPoint Reader.

## Download / Скачать

**`NookPoint-@VERSION@.apk`** is under *Assets* below. / APK лежит в разделе *Assets* ниже.
SHA-256: `@SHA256@`

## Install / Установка

1. The Nook must be rooted (for example with NookManager). / Nook должен быть рутован (например, через NookManager).
2. Enable USB debugging and run `adb install -r NookPoint-@VERSION@.apk`, or copy the file to the card and open it with a file manager (ReLaunch). / Включите отладку по USB и выполните `adb install -r NookPoint-@VERSION@.apk`, либо скопируйте файл на карту и откройте файловым менеджером (ReLaunch).
3. Put books into `Books/`, or send them over Wi-Fi from the app (**Wi-Fi** button). / Положите книги в `Books/` или отправьте их по Wi-Fi из приложения (кнопка **Wi-Fi**).

Updating: install the new APK over the old one; your settings, positions and notes are kept. Back them up first in *Settings → Back up data*. / Обновление: установите новый APK поверх старого, настройки, позиции и заметки сохранятся. Сначала сделайте копию: *Настройки → Сохранить данные*.
