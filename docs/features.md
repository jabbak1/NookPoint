## What is inside / Что внутри

| | |
|---|---|
| **Formats** / Форматы | EPUB 2/3, FB2 (+ `.fb2.zip`), TXT (UTF-8 / Windows-1251) |
| **Typesetting** / Вёрстка | bold/italic, headings, lists, quotes, CSS of the book, justified text, hyphenation by real TeX patterns (ru, uk, en, fr, es, de, it, pt, bg), widow/orphan control, pictures with E Ink contrast |
| **Reading** / Чтение | page-turn buttons or edge taps, footnote pop-ups, links with a Back stack, bookmarks, highlights and notes, full-text search, time left, reading goals and statistics |
| **Library** / Библиотека | list, grid and **bookcase** view with covers, search, sort, filters, series, **visual shelves**, book info with annotation |
| **Dictionaries** / Словари | StarDict and dictd (even huge ones), long-press a word, saved-words list with export for flash cards |
| **Fonts** / Шрифты | Lora, IBM Plex Serif, DejaVu Serif/Sans built in, your own `.ttf` in `fonts/` |
| **Online** / Онлайн | OPDS catalogs (your Calibre server), Wi-Fi book transfer |
| **Safe** / Надёжность | weekly automatic backups, restore, error log |
| **Languages** / Языки | English, Русский, Français, Español |
