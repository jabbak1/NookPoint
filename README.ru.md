# NookPoint

Читалка для **Nook Simple Touch** (Android 2.1, E Ink) и других старых Android-устройств, вдохновлённая прошивкой CrossPoint Reader: спокойная, минималистичная, сделанная под E Ink.

## Возможности

- **Форматы:** EPUB 2/3, FB2 и `.fb2.zip`, TXT (UTF-8 или Windows-1251).
- **Вёрстка:** жирный и курсив, заголовки, списки, цитаты, CSS книги, выравнивание по ширине, переносы по настоящим шаблонам TeX (русский, украинский, английский, французский, испанский, немецкий, итальянский, португальский, болгарский), запрет вдов и сирот, предлоги и тире не остаются в конце строки, картинки с контрастом для E Ink и просмотром на весь экран.
- **Чтение:** кнопки листания или касание краёв, окна сносок, ссылки с возвратом кнопкой «Назад», закладки, выделения с заметками (экспорт в текст), поиск по тексту, время до конца главы или книги, цели по чтению и статистика, полное обновление экрана каждые N страниц.
- **Библиотека:** вид списком, сеткой и **книжным шкафом** с обложками и прогрессом, поиск, сортировка, фильтры, серии, **наглядные полки**, информация о книге с аннотацией.
- **Словари:** StarDict и dictd, в том числе огромные; долгое нажатие на слово; список сохранённых слов с экспортом для карточек.
- **Шрифты:** встроены Lora, IBM Plex Serif, DejaVu Serif и Sans (кириллица и акценты) или ваши `.ttf` в папке `fonts/`.
- **Онлайн:** каталоги OPDS (например, ваш сервер Calibre), передача книг по Wi-Fi.
- **Надёжность:** еженедельные автоматические резервные копии, восстановление, журнал ошибок для поддержки.
- **Языки:** English, Русский, Français, Español.

## Установка

1. Получите root на Nook (например, через NookManager).
2. Скачайте `NookPoint-<версия>.apk` из раздела [Releases](../../releases) и выполните `adb install -r NookPoint-<версия>.apk`, либо скопируйте файл на карту и откройте файловым менеджером (например, ReLaunch).
3. Положите книги в папку `Books/` на карте или отправьте их кнопкой **Wi-Fi** с телефона или компьютера.

Обновление: установите новый APK поверх старого. Сначала сделайте копию: *Настройки → Сохранить данные*.

## Как пользоваться

| | |
|---|---|
| Листание | кнопки Nook или касание левого/правого края |
| Меню | касание середины страницы (или клавиша Menu/центр) |
| Закладка | касание правого верхнего угла |
| Словарь / выделение | долгое нажатие на слово |
| Сноска | касание маленькой цифры; «Назад» возвращает |
| Картинка | касание: на весь экран; ещё касание: масштаб, удержание: поворот |

**Словари:** положите папки StarDict (`.ifo`, `.idx`, `.dict`/`.dict.dz`) или пары dictd в `dictionaries/` (архивы `.zip` и `.tar.gz` распаковываются сами). *Настройки → Словари* покажут, что найдено и почему что-то пропущено.

**Онлайн-каталоги:** *Онлайн → Добавить каталог*, например `http://192.168.1.10:8080/opds` для сервера Calibre. Android 2.1 плохо работает с https, поэтому лучше обычный http в домашней сети.

## Собрать самому

Android SDK на компьютере не нужен: загрузите проект на GitHub, и встроенный workflow (`.github/workflows/build.yml`) соберёт APK, подпишет его и опубликует релиз с описанием.

Чтобы обновления всегда ставились поверх прежней версии, сохраните один ключ подписи: запустите workflow вручную с включённым *show_key*, скопируйте текст ключа из итогов запуска в секрет репозитория `KEYSTORE_B64`, а если репозиторий публичный, удалите тот запуск.

## Известные ограничения

- Логика проверена на компьютере; на реальном устройстве поведение может отличаться. Присылайте проблемы вместе с журналом ошибок (*Настройки → Показать журнал ошибок*).
- Картинки внутри строки текста показываются отдельными блоками; SVG-картинки пропускаются.
- Защищённые (https) онлайн-каталоги на Android 2.1 могут не работать.
