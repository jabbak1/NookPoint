# NookPoint

Минималистичная читалка EPUB/TXT для Nook Simple Touch (Android 2.1, API 7) в духе CrossPoint Reader (Xteink X4).

## Как получить APK (без установки SDK)
1. Создай бесплатный аккаунт на github.com и новый репозиторий (New repository).
2. Загрузи ВСЁ содержимое этой папки в корень репозитория (Add file -> Upload files).
   Папка `.github` с файлом `workflows/build.yml` обязательно должна попасть в репозиторий.
   Если её не видно при перетаскивании: Add file -> Create new file, имя `.github/workflows/build.yml`, вставь содержимое файла build.yml.
3. Открой вкладку **Actions**. Сборка стартует сама (или Run workflow). Через 2-3 минуты откроешь завершённый запуск и внизу в Artifacts скачаешь **NookPoint-apk** (zip, внутри NookPoint.apk).
4. Если сборка красная — открой её, скопируй текст ошибки и пришли мне.

## Установка на Nook
Нужен рутованный Nook (например, NookManager) с включённой отладкой по USB:
`adb install NookPoint.apk`
Либо положи APK на карту и открой файловым менеджером (ReLaunch и т.п.).
Обновление поверх старой версии работает, пока ключ подписи в кэше GitHub (до 7 дней простоя); иначе сначала удали старую.

## Что нового в 0.2
* Обложки: в библиотеке, на главном экране (карточка «Continue reading» и ряд последних книг). Кэшируются, для книг без обложки рисуется заглушка с названием.
* Статистика (кнопка Stats): время сегодня, серия дней, прочитано книг, график за 7 дней, итоги, скорость чтения, самые читаемые.
* Новое оформление: полосы прогресса, рамки, кнопки внизу, прогресс-бар в строке статуса читалки.

## Что нового в 0.6 (словари)
* **Settings → Dictionaries** показывает, что приложение нашло: установленные словари (с числом слов и путём), папки, где оно искало, файлы, которые не удалось использовать (с причиной), и прочие файлы в папках словарей. Если словарь «не виден», откройте этот экран.
* Поиск словарей стал терпимее: папка называется как угодно в любом регистре (`dictionaries`, `Dictionaries`, `Dict`, `StarDict`, `Словари`...), ищется на карте и на microSD (`external_sdcard`), а также в `Books` и `Download`. Если ничего не найдено, делается глубокий поиск по всей карте.
* Расширения файлов любого регистра (`.IFO`, `.IDX`).
* Новые форматы: `.idx.gz`, пара dictd (`.index` + `.dict.dz`), архивы `.zip` и `.tar.gz` (распаковываются автоматически).
* Неправильно отсортированный индекс больше не ломает поиск (используется последовательный поиск). Форматы `.dsl`, `.mdx`, `.bgl`, `.xz`, `.bz2` нужно сначала конвертировать в StarDict (например, программой PyGlossary).

## Что нового в 0.5
* **Библиотека** теперь плоская: сразу видны все книги (из `Books`, корня карты, `Download` и `external_sdcard`), без хождения по папкам. Кнопка Back ведёт на главный экран.
* **Поиск** по названию, автору и имени файла; **сортировка** (название, автор, недавно читал, прогресс, дата добавления); **фильтр** (все, читаю, новые, прочитанные); вид **список** или **сетка** с обложками. Выбор запоминается.
* Долгое нажатие на книгу: открыть, отметить прочитанной или непрочитанной, удалить файл.
* Названия дней недели и месяцев теперь вшиты в приложение (на русском, французском, испанском), поэтому вместо цифр в статистике показываются «Пн Вт Ср…».

## Что нового в 0.4
* **Шрифты.** В приложение встроены Lora, IBM Plex Serif, DejaVu Serif и DejaVu Sans (кириллица, французский, испанский, полные начертания: жирный и курсив). Выбор: Settings → Font. Свои шрифты: положи `.ttf` в `/sdcard/fonts` (рядом можно положить `Имя-Bold.ttf`, `Имя-Italic.ttf`, `Имя-BoldItalic.ttf`, они подхватятся как начертания). Интерфейс тоже использует встроенный шрифт, поэтому русские буквы не зависят от системных шрифтов Nook.
* **Словари.** Формат StarDict (`.ifo` + `.idx` + `.dict` или `.dict.dz`). Положи папку словаря в `/sdcard/dictionaries` или загрузи файлы через Wi-Fi (они сами попадут в нужную папку). Поиск: долгое нажатие на слово в тексте или меню → Dictionary → ввод слова. Ищутся словоформы (например, «книги» найдёт «книга») и показываются похожие слова. При первом поиске словарь индексируется (для больших это секунды), индекс сохраняется рядом со словарём.
* **Язык интерфейса:** русский, французский, испанский, английский. Settings → Language (первая строка), по умолчанию «Auto» по языку системы.
* **Закладки.** Нажми правый верхний угол страницы, чтобы поставить или снять закладку (на странице с закладкой в углу чёрный треугольник). Список: меню → Bookmarks, крестик удаляет закладку.
* **Чище экран.** Убраны надпись «(no text in this section)» (пустые страницы вроде обложки-картинки пропускаются автоматически), «BAT 85%» (вместо этого значок батареи, в настройках можно выбрать «Percent» или «Off») и подпись «Section N»; подсказка про кнопку Back теперь показывается один раз.

## Что нового в 0.3
* **Ссылки и сноски.** Нажми на ссылку в тексте (подчёркнута): маленькая цифра-сноска открывает окно с текстом примечания («Close» / «Go there»), обычная ссылка переходит к цели, а кнопка Back (или пункт меню «Back to previous place») возвращает на прежнее место. Внешние http-ссылки показывают адрес.
* **Вёрстка:** жирный и курсив, заголовки по центру разных размеров, переносы слов (русский и латиница), выравнивание по ширине без «дырок», висячие предлоги и тире не остаются в конце строки (неразрывные пробелы тоже учитываются), списки с маркерами, цитаты, центрирование и отступы из CSS книги, скрытые элементы, запрет вдов и сирот и заголовков внизу страницы.
* **Настройки:** Hyphenation, Paragraph spacing, Underline links.
* **Цели по чтению** (Stats → GOALS): ежедневная в минутах и годовая в книгах, прогресс-бары, серия выполненных дней, линия цели на графике, прогресс на главном экране, всплывающие уведомления «Daily goal reached» и «Book finished».

## Книги
* Папка `Books` во внутренней памяти (`/sdcard/Books`), либо любая другая через «Browse files».
* По Wi-Fi: «File transfer», откроется адрес вида http://192.168.x.x:8080, загрузка с телефона или компьютера.
* Шрифты (.ttf/.otf) для кириллицы и т.п.: папка `/sdcard/fonts`, выбор в Settings -> Font.

## Управление
* Кнопки листания Nook, либо касание левого/правого края экрана.
* Касание центра / кнопка Menu: оглавление, размер текста, настройки, выход в библиотеку.
* Back: выход. Позиция чтения сохраняется автоматически.
* Если кнопки не листают: Settings -> Key test покажет код кнопки.
